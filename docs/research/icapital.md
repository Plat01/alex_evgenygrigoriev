# iCapital — наблюдения 28.10.2026

Источник: https://www.icapital.es/. Сайт доступен, реально открыт Playwright MCP. Просмотрены скриншоты 1920×1080 и 390×844, скролл wheel, верх/промежуточные сцены. Cookie consent отклонён. Изображения — исследовательские скриншоты, не ресурсы лендинга.

## Наблюдения по изображению и движению
- Первый экран: тёмно-синее небо, горы, облака, маленький путешественник. Текст отделён от активного переднего плана большим полем неба.
- При прокрутке кадр держится в viewport; горы, облака и фигура меняются с разной скоростью/масштабом. Снег/облако закрывают кадр при смене сцены.
- Следующие кадры: снежный гребень → горная долина → тропа/сосны/море на закате. Центральный путешественник связывает разные окружения.
- Короткие сообщения плавно появляются и исчезают; в промежуточных кадрах текст бывает полупрозрачным. Контраст некоторых промежуточных кадров слаб — это не следует повторять.
- Небольшая шапка остаётся наверху, справа у desktop указатель пути; на мобильном прогресс расположен внизу. Есть кнопка перехода вниз.
- Mobile после перезагрузки: узкая вертикальная композиция, герой центрирован, текст в верхней трети, интерфейс по краям. Сцены не просто уменьшены целиком.
- Проверка resize с desktop на mobile без reload показала промежуточные несогласованные состояния сцен. После reload сняты отдельные mobile кадры; для собственного сайта нужно проверять также resize после загрузки.

## Что является предположением
Раздельные DOM-слои и scrub/pin — вероятная техника, но исходный код анимаций не исследован; точные easing, тайминги, библиотека и метод рендера не установлены. По статичным скриншотам нельзя измерить FPS. Фиксация движения основана на скролле и последовательных кадрах, не на видеозаписи.

## Что переносить
Глубина через раздельные слои; герой как якорь идентичности; смена окружения как сюжетный переход; стабильная зона текста. Не копировать чужие горы, фотографии, брендинг или коммерческие тексты. На нашем проекте персонаж и среды должны быть стилизованы согласно model sheet.

Скриншоты: docs/research/icapital/. Сдвиги 800/2500/4800/9400 относятся к desktop wheel; мобильные scene-0..3 сняты после reload при накопленной прокрутке 700/2500/5500/10500 CSS px. Фактическая компоновка может изменяться при viewport refresh и динамической высоте.

## Повторный просмотр при реализации
28.10.2026 английский URL /en/ прочитан через web и открыт установленным Playwright/Chromium в отдельном профиле. Скриншоты reference-en-current.png и reference-en-scroll-current.png. Прямой Playwright MCP вызван, но отказал из-за занятого профиля; чужой процесс и глобальные настройки не менялись. Принцип сохранён: герой связывает среду и смысл; графика iCapital не заимствуется. В собственной версии используются архитектурная лента, тёплые материалы и короткое закрепление одной сцены вместо длинного последовательного pin всего сайта.
