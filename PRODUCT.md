## Platform
web

## Stack
Прямо задан пользователем: Astro static, TypeScript, CSS/SVG, GSAP + ScrollTrigger. GitHub Pages. Публикация только по отдельному поручению.

## Product Purpose
Подготовить проект к разработке одностраничного русскоязычного лендинга. Содержательного брифа на этапе подготовки нет; текущий маршрут — технический стенд, не финальный лендинг.

## Brand Commitments
Авторский стилизованный 3D персонаж из assets/Seven-view stylized character model sheet.png. Постоянство лица и телосложения обязательно. iCapital — референс движения и глубины.

## Open Decisions
Назначение лендинга, аудитория, предложение, основное действие, контакты и реальные факты должны поступить из содержательного брифа.
